# Harness 工程

以 harness（模型权重与环境之间的循环、上下文、工具与技能、子 agent、执行环境与运行时控制）为研究对象的设计、自动优化与演化、harness 与权重的联合优化与迁移、长程任务 harness、harness 安全，以及 harness 的评测与失败归因。Agent 定义与控制循环的入门概念归01；以递归自我改进机制本身为核心的工作归03；只把 harness 用作机器人、推荐、领域应用或记忆评测载体的工作留在原类，以副标签关联18。
