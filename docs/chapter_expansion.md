# 章节组织与编辑规范

[首页](../README.md) · [贡献指南](../CONTRIBUTING.md) · [质量标准](quality_review.md)

## 面向读者的结构

专题以研究方向为单位组织，不以整理过程或某次检索批次为叙事主线。读者应能先理解为什么需要研究这个方向，再识别核心问题、方法分支及其联系。

建议采用以下顺序：

1. **方向背景：** 说明需求、重要性、研究对象和与相邻领域的边界。
2. **基础概念：** 定义必要术语和机制，提供按需补充的前置知识链接。
3. **经典发展脉络：** 选择有基础性作用的经典与代表工作，不限发表时间；先总述问题，再解释路线，不将发布时间先后强行写成替代关系。优先解释对后续研究产生影响的概念、任务和方法。
4. **前沿研究方向：** 围绕趋势论文归纳当前问题，先总述分支关系，再比较具体工作。经典用于解释来路，不混入前沿清单充当近期进展。
5. **综合比较：** 对照改变的组件、依赖假设、资源成本和证据条件。
6. **开放问题与研究机会：** 区分已知局限、未来能力目标与可检验的研究方案。

## 分支说明

章、节与分支尽量采用总分结构。发展脉络先回答需要解决什么、为什么分成这些路线；前沿部分先交代展开顺序及相互关系。不要在标题后立即放论文名或未定义的术语，也不要用相邻段落重复概括同一问题。

章节与配套说明不展示数学公式，也不引入只为计算而设的字母记号。用自然语言解释对象、过程、变化关系和适用条件；改写时保留关键机制与限制，不只是删除表达式。需要完整推导或算法细节时，引向原始论文。论文题名、方法名称与原始文献数据保持准确，不为避免符号而篡改引用。

分支引言应回答：为什么现有做法不足？哪些变量需要设计？不同路线付出什么代价？什么证据能够判断改进有效？避免只将标题改写成一个问句，随后直接排列论文。

论文导读应明确研究目标、方法变化及证据边界。多个工作放在一起时，解释它们是互补、竞争还是作用于不同阶段；不把不可比的分数并列为排名。补充论文融入对应问题的叙述，不在每段后附加独立的文献清单。表格用于比较能力、方法或实验条件，完整题名索引交由文献目录承担。

## 公共文档表达

正文使用面向研究主题的说明，不包含面向特定委托者的称呼或沟通过程措辞，也不以虚构人物或任务故事作为章节开头。研究论文中的实际实验和失败分析可以保留，但需明确来源与范围。

文献目录呈现题名、原始链接与关联方向。数据导入、规则命中和历史类别转换记录保留在机器可读数据中；维护文档说明字段与方法，不在每条文献旁重复展开迁移日志。

专题正文聚焦研究内容，不附加来源处理流程、覆盖计数、检索批次或核验状态说明，也不在论文旁重复展示内部状态标签。保留直接引用、必要的版本信息与影响结论的实质性限制；来源记录和统计由维护文档统一承载。
