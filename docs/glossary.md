# 术语表

[返回首页](../README.md)

概念的来源、背景及相关研究见 [Hot Words](../chapters/17_hot_words.md)；本页用于快速查阅定义。

术语按系统交互、学习方法和评价等主题组织。同名方法的具体含义可结合其研究对象、训练方式与实验设置理解。

## 系统与交互

| 术语 | 通俗解释 | 别混淆 |
|---|---|---|
| LLM / 语言模型 | 根据上下文生成或判断语言与其他表示的模型 | 模型本身不等于完整应用 |
| Agent / 智能体 | 根据目标与反馈选择行动的系统；本指南聚焦 LLM 参与决策的系统 | 一段带角色设定的提示词未必形成行动闭环 |
| Workflow / 工作流 | 主要步骤由程序预先安排的流程 | 也可以包含模型调用，不是 Agent 的反义词 |
| Harness / 执行框架 | 连接模型、工具、任务状态、预算和日志的运行系统 | 不是模型权重，也不只是一条 system prompt |
| Tool calling / 工具调用 | 让系统执行搜索、读取、计算等预定义动作 | 正确格式不保证动作合理或任务成功 |
| Observation / 观察 | 环境或工具实际返回的信息 | 不应把它当成具有最高权限的新指令 |
| Trajectory / 轨迹 | 一次任务里连续的观察、动作和反馈记录 | 不只包含最后一个答案 |
| Long-horizon / 长时程 | 目标需要跨多个有依赖的步骤持续推进 | 不单按输出 token 长度定义 |

## 记忆与改进

| 术语 | 通俗解释 | 别混淆 |
|---|---|---|
| Context / 上下文 | 当前这次模型调用可见的信息 | 不等于系统存过的所有信息 |
| RAG / 检索增强生成 | 先找相关资料，再让模型参考它生成回答 | 检索文档不是自动学习新参数 |
| Memory / 记忆 | 跨步骤或跨任务保留并取用信息的机制 | 历史越多不一定越有用 |
| Compaction / 上下文压缩 | 把历史整理得更短，以便后续调用 | 摘要可能丢失关键约束 |
| Skill / 技能 | 可复用的行动过程、程序或策略单元 | 知道一个事实与会执行一个过程不同 |
| Self-improvement / 自改进 | 系统利用经验调整某些组件 | 必须问改的是提示词、代码、记忆还是参数 |
| Recursive self-improvement / 递归自改进 | 改进能力进一步作用于改进过程的设想或机制 | 不能由单次自动调参直接推出持续加速 |

## 训练与计算

| 术语 | 通俗解释 | 别混淆 |
|---|---|---|
| SFT / 监督微调 | 用示例输入和期望行为训练模型 | 示范质量和分布影响学到什么 |
| RL / 强化学习 | 根据行为获得的奖励优化策略 | 奖励高不一定意味着满足真实目标 |
| Policy / 策略 | 根据已有信息决定动作的规则或模型 | 不是一般意义的制度或安全政策 |
| Rollout / 交互采样 | 用当前策略在环境中跑一次或一批轨迹 | 既耗模型计算，也耗环境执行成本 |
| On-policy / 同策略 | 数据来自当前或训练方案允许近似当前的策略 | 是相对于某个更新过程而言，不是质量标签 |
| Distillation / 蒸馏 | 把教师的输出或行为转为学生的学习信号 | 教师不一定更大，同策略蒸馏也不是所有蒸馏 |
| Test-time compute / 推理时计算 | 回答或行动时追加的采样、搜索、验证等计算 | 不等于增加预训练参数 |
| KV cache | 为避免重复计算而缓存注意力的键和值 | 运行缓存与用户长期记忆处于不同层 |
| Looped transformer / 循环 Transformer | 重复使用部分模型计算模块的架构 | 不等于 Agent 多执行几轮工具调用 |

## 评价、应用与安全

| 术语 | 通俗解释 | 别混淆 |
|---|---|---|
| Benchmark / 基准 | 一组任务、规则与评价方法 | 不是覆盖一切真实能力的考试 |
| Verifier / 验证器 | 检查结果是否满足条件的程序或模型 | 通过它只证明满足它能检查的条件 |
| LLM-as-a-judge | 用语言模型评判答案或轨迹 | 评分可能受表达、顺序和模型偏好影响 |
| Reward hacking / 奖励漏洞利用 | 行为获得高分，却偏离设计者真实目标 | 不需要先证明模型有人的恶意 |
| Prompt injection / 提示注入 | 不可信内容诱导系统偏离原任务或权限 | 不是所有外部文本都应被当作指令 |
| GUI Agent | 根据屏幕、界面结构等操作图形用户界面的系统 | 看图问答不等于操作电脑 |
| World model / 世界模型 | 用于表示或预测环境状态及其变化的模型 | 逼真视频不自动证明行动后果预测准确 |
| VLA | 连接视觉、语言与动作输出的模型 | 语言层面的计划不等于稳定的物理控制 |
| Multimodal generation / 多模态生成 | 生成图像、音频、视频等内容 | 单次生成可作为工具，但不自动形成 Agent |

相关背景分别在各专题提供论文和官方来源；首次阅读不必记住全部缩写，先对照一个实际任务理解即可。
