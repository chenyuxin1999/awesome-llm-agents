# 文献收录与分类

[首页](../README.md) · [文献目录](../catalog/README.md) · [分类方法](classification_audit.md)

## 收录范围

本项目关注 LLM Agent 的系统设计、学习方法、能力评测与应用，并纳入与之密切相关的模型科学、世界模型和多模态生成研究。文献来源包括 AlphaXiv 趋势文献、专题检索、原始论文、作者项目页及官方技术报告。

经典工作用于解释概念与方法的来路；前沿工作按研究问题组织，比较各条路线的机制、效果与适用条件。综述导读提供全局框架，Hot Words 追溯新术语的来源及其研究联系。

## 分类原则

每条文献按主要研究问题确定一个主归属，方法、架构和应用场景作为关联方向。一篇使用蒸馏的机器人论文可以主归具身智能，同时关联训练方法；分类依据是主要贡献，而不是单个关键词。

相邻学科设独立入口。归属尚不明确的记录进入待复核目录，补齐主要贡献与来源信息后再调整。具体规则、人工校正与生成方式见[分类方法](classification_audit.md)。

## 引用与方法比较

引用优先指向原始论文、作者项目页或官方仓库。题名随版本变化时，保留版本对应关系；涉及某一版特有的方法或结果，链接到相应版本。已记录的变化见[版本说明](version_notes.md)。

方法比较围绕研究对象、改变的组件、实验设置和结果展开。模型、任务、工具权限、计算预算与评分方式会影响结果，应在相关讨论中交代。作者报告的结果、跨工作的综合分析与未来研究设想分别表述。

## 数据与统计

`data/papers.jsonl` 保存 2050 条文献记录；分类配置和维护脚本随项目提供。跨章引用按文献标识去重，正文引用的补充文献单独统计。目录收录与正文讨论的对应关系见[覆盖报告](coverage.md)。

来源文件保留原始地址、版本及访问记录，见[来源索引](../sources/README.md)。这些字段用于维护引用，不在专题正文中重复展示。

## 更新与纠错

补充文献时，将其放入对应研究问题的讨论，并说明与已有工作的关系。引用修正同步更新正文及来源记录；分类修正通过配置重建目录。流程见[贡献指南](../CONTRIBUTING.md)，检查要求见[质量标准](quality_review.md)。
