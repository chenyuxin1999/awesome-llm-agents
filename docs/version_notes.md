# 论文题名与版本对应

[返回首页](../README.md) · [方法与证据](methodology.md) · [来源记录](../sources/README.md)

论文在修订时可能同时调整题名、研究范围与实验内容。下表记录同一文献不同版本的对应关系，便于沿引用查找相应方法与结果。

| ID | 正文引用版本 | 后续版本 | 版本更新时间 |
|---|---|---|---|
| 2607.12815 | [v1：Visual Access Boundaries in Vision-Language Model Reasoning](https://arxiv.org/abs/2607.12815v1) | [v3：What Keeps Vision-Language Models Looking at the Image?](https://arxiv.org/abs/2607.12815v3) | 2026-10-04 09:34:10 UTC |
| 2607.27599 | [v1：World Action Planner: Generalizable Decision-Making with Action-Conditioned World Models](https://arxiv.org/abs/2607.27599v1) | [v2：World Action Planner: Generalizable Robot Decision-Making with Action-Conditioned World Models](https://arxiv.org/abs/2607.27599v2) | 2026-10-02 17:25:59 UTC |
| 2607.28627 | [v1：ReToken: One Token to Improve Vision-Language Models for Visual Retrieval](https://arxiv.org/abs/2607.28627v1) | [v2：ReToken: Improving Long-Context VLMs with Visual Retrieval Token](https://arxiv.org/abs/2607.28627v2) | 2026-10-06 22:51:13 UTC |

特别是 `2607.12815`，v3 不只是换了标题。新版摘要研究生成答案时的图像依赖，讨论所需属性何时已经通过文字表达，以及问题处理阶段是否访问图像对后续依赖的影响。v1则围绕 Visual Access Boundary 展开。两个版本有联系，但不能把 v3 的实验范围与 v1 的结论混为一谈。

相关正文引用 v1 的方法，并提供后续版本入口。文献数据保留原题名，版本对应表用于关联同一工作的不同修订。

版本元数据见 [versioned_papers.json](../sources/versioned_papers.json)、[官方 API 响应](../sources/version_changes_2026-10-08.xml)和 [title_versions.json](../sources/title_versions.json)。
